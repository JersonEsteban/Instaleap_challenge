# Instaleap Challenge – Angular First App

Este proyecto sigue paso a paso el tutorial oficial “Build your first Angular app”, implementando 14 lecciones que cubren conceptos fundamentales: componentes standalone, inputs, templates, servicios, inyección de dependencias, routing, formularios y peticiones HTTP con fetch.

Aprendí cómo estructurar una aplicación Angular moderna utilizando  componentes reutilizables, comunicación entre componentes y consumo de datos desde un servidor local usando JSON Server. El proyecto fue generado usando Angular v16.01

### Librerías adicionales
 TailwindCSS: Se agregó para mejorar el diseño y estilos responsivos. Instalación:
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init
### Cómo ejecutar el proyecto
1. Instalar dependencias: npm install
2. Iniciar Angular: npm run start
3. Iniciar JSON server: json-server --watch db.json
